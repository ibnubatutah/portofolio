TYRANT Payment System

TYRANT is a web-based payment and business administration system developed as a practical project to explore the end-to-end workflow of digital transactions, from service selection and order creation to payment processing and transaction status management.

The system combines a PHP-based backend with a MySQL database and a responsive JavaScript interface. AJAX is implemented to handle asynchronous communication between the frontend and backend, allowing transaction data, payment status, and system responses to be processed dynamically without requiring full page reloads.

TYRANT also integrates the Midtrans Payment Gateway through the Snap API to simulate real-world online payment processing. The system is designed to demonstrate how authentication, service packages, transaction records, payment processing, status checking, and administrative workflows can be connected into a single web application.

Technical Implementation

The application follows a modular web application architecture where the frontend communicates with backend PHP endpoints through HTTP requests. AJAX is utilized for asynchronous requests such as retrieving transaction data, checking payment status, processing user interactions, and communicating with backend APIs.

The payment workflow is integrated with Midtrans Snap, while transaction records are maintained in MySQL. This architecture provides a practical representation of how a payment system can connect frontend interfaces, backend business logic, database persistence, and third-party payment services.

Project Objective

This project was developed as a technical exercise to strengthen practical skills in web development, backend programming, database management, API integration, asynchronous JavaScript processing, and payment system workflows.

The main focus was not only on the visual interface, but also on understanding how different components of a web application communicate with each other throughout the complete transaction lifecycle.
