TYRANT Payment System

TYRANT Payment System is an enterprise-inspired payment and business administration web application developed with Laravel 9 as a practical full-stack project that demonstrates how modern payment systems manage authentication, transactions, payment processing, and administrative workflows within a unified application.

The project adopts Laravel's MVC architecture to separate business logic, presentation, and data management while utilizing Blade Templates for the frontend and Eloquent ORM for database interactions. AJAX communication is implemented throughout the application to process transaction requests, payment status updates, and dashboard interactions dynamically without requiring full page reloads.

A significant focus of this project is the integration of Midtrans Snap API, allowing users to experience a realistic online payment workflow including transaction creation, payment processing, payment resume functionality, payment status synchronization, and notification handling through backend API endpoints.

Technical Implementation

The application follows Laravel's MVC architecture, where routes, controllers, models, and Blade templates work together to manage the entire payment lifecycle. Business logic is organized inside controllers, while Eloquent ORM handles communication with the MySQL database for users, packages, and transaction records.

AJAX communication using the Fetch API enables seamless interaction between the frontend and backend APIs. Users can create transactions, retrieve payment information, resume pending payments, and refresh payment status without leaving the current page, resulting in a smoother user experience.

The payment flow integrates Midtrans Snap.js for secure payment simulation, while backend endpoints validate transactions, generate Snap Tokens, update payment status, and synchronize transaction records. The implementation demonstrates how frontend interfaces, backend services, databases, and third-party payment providers operate together within a production-oriented architecture.

System Workflow

The payment workflow follows a structured enterprise transaction lifecycle.

  • User registers and authenticates using Laravel Breeze.
  • User selects an available service package.
  • Laravel generates a unique transaction record.
  • Backend requests a Snap Token from Midtrans.
  • Snap.js opens the payment interface.
  • Payment status is synchronized through AJAX requests.
  • Pending payments can be resumed.
  • Completed transactions are stored and displayed inside the dashboard.

Database Design

The project utilizes a relational MySQL database managed through Laravel's migration system. Core entities include:

  • Users
  • Packages
  • Transactions

Eloquent ORM simplifies CRUD operations while maintaining a clean separation between application logic and database interactions.

Challenges & Solutions

During development, several real-world implementation challenges were encountered, particularly around payment gateway integration and server-side communication.

  • Integrated Midtrans Snap API within Laravel.
  • Implemented AJAX-based payment status updates.
  • Built a payment resume mechanism for pending transactions.
  • Handled transaction synchronization between frontend and backend.
  • Organized API endpoints following Laravel's routing structure.

These implementations helped simulate practical scenarios commonly found in modern digital payment applications.

Project Objective

TYRANT Payment System was developed to strengthen practical full-stack development skills through the implementation of Laravel, AJAX, database management, authentication systems, REST API communication, and payment gateway integration within a single enterprise-inspired application.

Rather than focusing solely on interface design, the project emphasizes the complete transaction lifecycle—from user authentication and order creation to payment processing, transaction synchronization, and administrative data management—reflecting workflows commonly found in modern business applications.
