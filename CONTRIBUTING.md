# Panduan Kontribusi

Terima kasih telah tertarik untuk berkontribusi pada proyek ini! Kami sangat menghargai bantuan Anda untuk membuat proyek ini menjadi lebih baik.

## Cara Berkontribusi

### 1. Melaporkan Bug
Jika Anda menemukan bug, silakan buat *Issue* baru dengan menjelaskan:
* Langkah-langkah untuk mereproduksi bug tersebut.
* Hasil yang diharapkan vs hasil yang terjadi.
* Screenshot (jika ada).

### 2. Mengusulkan Fitur
Kami selalu terbuka untuk ide baru! Silakan buat *Issue* dengan label `enhancement` untuk mendiskusikan fitur yang ingin Anda tambahkan.

### 3. Pull Request (PR)
Jika Anda ingin memperbaiki bug atau menambah fitur secara langsung:
1. **Fork** repositori ini.
2. Buat branch baru (`git checkout -b fitur-keren-anda`).
3. Lakukan perubahan dan **commit** (`git commit -m 'Menambahkan fitur keren'`).
4. **Push** ke branch Anda (`git push origin fitur-keren-anda`).
5. Buat **Pull Request** ke branch `main`.

## Standar Kode
* Gunakan penamaan variabel yang jelas.
* Pastikan kode sudah dites dan tidak merusak fitur yang sudah ada.
* Ikuti struktur folder yang sudah disediakan.
